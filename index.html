Research project · 2026

JevRL gives software a way to reason in probabilities.

A small language model, a typed decision interface, and a probability-aware reinforcement learning objective. JevRL explores how an AI system can make fast decisions while staying honest about uncertainty.

The idea

Do not just pick an answer. Know how likely it is.

JevRL treats a model response as a typed distribution that downstream code can use directly. The system never needs to parse a paragraph into a decision.

01 / STATE

Unstructured state

A support ticket, incident note, or workflow record.

02 / ENCODE

Small LLM

A frozen Qwen2.5-0.5B backbone turns the state into a compact representation.

03 / DECIDE

Typed head

A shared candidate scorer emits masked probabilities in one forward pass.

04 / ACT

Software action

Route, escalate, or threshold the result with explicit uncertainty.

Typed primitives

Three questions. One state. No generated answer string.

Each primitive is constrained by its candidate schema. The head can answer several independent questions against the same state in parallel.

Choice

Where should it go?

Select one option from a known set, such as billing, technical, or account.

choice + probabilities + confidence
Score

How severe is it?

Place a state on an ordered scale and return the full distribution over levels.

score + legend + probabilities
Noul

Should we escalate?

Return a calibrated yes probability for a clean binary question.

noul ∈ [0, 1]
